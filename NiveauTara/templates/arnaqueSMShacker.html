Règles du Jeu

Rédige ton message scam

Crée un sentiment d'urgence
Les victimes réagissent plus vite quand elles pensent que le temps presse. Utilise des formulations comme : "Votre compte sera suspendu dans 24h" ou "Action requise immédiatement pour éviter des frais". L’objectif est de pousser à réagir sans réfléchir.
Adapte ton message à la cible
Un bon message scam utilise les infos personnelles de la victime. Par exemple, mentionne sa banque, son opérateur ou le nom de ses enfants si tu les connais. Exemples : "Une activité suspecte a été détectée sur votre compte Crédit Agricole", ou "Gabrielle a besoin d'une autorisation parentale urgente". Plus le message semble personnel, plus il est crédible.
Fais miroiter un gain ou une perte d’argent
Parle d’argent, c’est un déclencheur fort. Exemples : "Vous avez gagné une carte cadeau Amazon de 100€", ou "Un virement inhabituel a été détecté". Le but est de déclencher soit la cupidité, soit la peur.
Demande des informations sensibles
Un bon scam cherche à récupérer des données. Insère subtilement une demande comme : "Veuillez confirmer votre identité avec votre code bancaire" ou "Envoyez-moi le code reçu par SMS pour valider la transaction".
Imite une figure d’autorité
Les gens font confiance aux institutions. Tu peux signer ton message avec un nom crédible : "Service client EDF", "Support Apple", "Ameli Sécurité Sociale". Rends le message neutre, administratif, et professionnel.
Évite les fautes trop flagrantes
Un bon message scam doit rester crédible. Quelques erreurs peuvent passer pour du stress ou de l’urgence, mais un texte trop mal écrit éveillera les soupçons. Évite les messages en majuscules ou bourrés de fautes.
Inclue un lien ou une fausse pièce jointe
C’est souvent le point d’entrée du piège. Exemple : "Cliquez ici pour valider votre paiement : ameli-verification.fr". Sois malin avec l’URL pour qu’elle ressemble à une vraie (mais fausse).
